# LeKiwi 약통 픽업 데모

공학경진대회 제출용 데모 — 음성 명령으로 LeKiwi가 책상 위 약통을 찾아 집는 파이프라인.

에이보(별도 저장소 `robot_ws`)와 SSH로 연동된다. 설계 문서:
`docs/superpowers/specs/2026-08-12-lekiwi-pill-pickup-design.md`

## 자율주행 (이동 부분)

집기 전후의 **이동** — 지도 만들기(SLAM), 위치추정(AMCL), 목표까지 자율주행(Nav2),
왕복 미션 — 은 [`nav/`](nav/README.md) 에 있다. 집기와는 ROS2 토픽 두 개로만
붙는다: 도착하면 `/abo/pick_request` 를 발행하고, `/abo/pick_done` 을 받아야
복귀를 시작한다.

## 전체 테스트 돌리기 혼자 실행하는 방법

노트북 ~/lekiwi_mission/에 스크립트 네 개를 만들었어요.

명령: bash ~/lekiwi_mission/start_all.sh
하는 일: 한 번에 켜기. 이미 떠 있는 건
건너뛰어요. 에이보 파이 노드(웹 "전체 시작"),
 노트북 노드 7개, 르키위 주행 스택 순서예요.
────────────────────────────────────────
명령: bash ~/lekiwi_mission/status.sh
하는 일: 켜졌는지 확인. 각 노드 ✅/❌, 르키위
위치 맞춤 결과, 브리지 준비 여부, 실시간 기록
 보는 명령을 보여 줘요.
────────────────────────────────────────
명령: bash ~/lekiwi_mission/stop_all.sh
하는 일: 노트북 노드와 르키위 주행 스택 끄기.
--abo를 붙이면 에이보 파이 노드까지 꺼요.
────────────────────────────────────────
명령: ~/lekiwi_mission/config.sh
하는 일: 에이보·르키위 IP와 모델·코드 경로.
네트워크가 바뀌면 여기만 고치면 돼요.

## 혼자 할 때 순서
1. 르키위를 시작 표시 위에 두고, 블루투스 스피커가 에이보에 연결됐는지 확인
2. bash ~/lekiwi_mission/start_all.sh
3. 약 60초 뒤 bash ~/lekiwi_mission/status.sh로 전부 ✅이고 "브리지 준비 완료"인지 확인
4. 에이보에게 말하기(또는 웹 🧪 르키위 탭 버튼)
5. 에이보가 한 말과 르키위 상태 보기: status.sh 마지막 줄의 tail -f .../topics.log
6. 끝나면 bash ~/lekiwi_mission/stop_all.sh

⚠️ 아직 한 번도 실행해 보지 않았어요. 문법 확인과 버그 하나 수정(르키위 쪽 확인 명령이 자기 자신을 찾던 문제)까지만 했어요. 지금 켜진 것들을 다시 켜게 되기 때문이에요. 발화 테스트가 끝나면 stop_all.sh → start_all.sh → status.sh를 실제로 돌려서 검증해 드릴게요
